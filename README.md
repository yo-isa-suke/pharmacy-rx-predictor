# 調剤ツール（医療機関ファインダー／薬局ファインダー／出店分析ツール）

## 使い方（チーム向け）
共通URLを開き、画面左のメニューでツールを切り替えます（最初に開くのは出店分析ツール）。
更新はこのリポジトリに反映されると、全員の画面に自動で反映されます（何もしなくてよい）。

**同時に使いたいとき**：同じタブの中でメニューを切り替えると、実行中の分析はそこで止まります。
出店分析ツールを動かしながらファインダーを使うときは、左メニューの「別タブで開く ↗」から開いてください。
タブが別なら、それぞれ同時に動きます。

| ツール | 内容 | 最新版 |
|---|---|---|
| 🏪 出店分析ツール | 出店候補地ごとに獲得処方箋枚数を2通りで予測し、Excelに出力 | v2.2 |
| 🏥 医療機関ファインダー | 住所とゾーンで周辺の医療機関を一覧（院内外処方・外来患者数・診療日・診療科、外来不明には参考値） | v4.1 |
| 💊 薬局ファインダー | 住所と半径で周辺の調剤薬局を一覧（門前/面・年間処方箋数） | v2.1 |

## フォルダ構成
```
tools_portal.py      ← 共通URLの入口（3ツールを1つのアプリで切り替え・別タブで開くリンク付き）
tools/               ← 動いている最新版。更新はここのファイルを差し替えるだけ
versions/            ← 各ツールの「最新版＋2つ前」の版番号付きファイル（戻したいとき用）
archive/             ← それより古いファイル・使わなくなったツール（参照用に保管）
requirements.txt     ← 必要なライブラリ
medical_finder.py / pharmacy_area_finder.py / 薬局出店分析ツール.py
pharmacy_rx_predictor/（中身は同名の3ファイル＋requirements.txt）
                     ← 旧URL互換の入口。中身は tools/ の最新版を呼ぶだけ。
                       チームが共通URLに移り終えたら削除してよい
```
`bento-diary/` と `.github/` は別プロジェクト（お弁当日記）のもの。

## 更新のしかた（管理者向け）
1. 新しい版を `versions/<ツール>/` に版番号付きで追加する（例：`medical_finder_v4_2.py`）。
2. 同じ中身で `tools/` のファイルを上書きする（ファイル名は変えない）。
3. `versions/` に4つ以上たまったら、いちばん古いものを `archive/` へ移す。
4. commit して push。Streamlit Cloud が1分ほどで自動で再デプロイする。

## データについて
- 各ツールは初回の検索時に、厚労省のオープンデータと地方厚生局の名簿を自動でダウンロードし、
  `tools/rx_tool_data/` に保存します（Gitには含めない）。アプリの再起動後は取り直すため、最初の1回だけ1〜2分かかります。
- 出店分析ツールには自社の予測前提（院外率・発行率など）が含まれます。お客様には「お客様提示用Excel」だけを渡してください。
