# 🍱 お弁当日記

毎日のお弁当の写真とひとことコメントを記録し、あとで1冊のアルバムとして書き出せる、私用のWebアプリです。サーバーもアカウントも不要で、データはすべて自分のスマホの中だけに保存されます。

## できること

- **記録**: お弁当の写真(カメラ撮影 or アルバムから選択)+ひとことコメント+日付を保存
- **一覧**: 記録を新しい順に振り返り。編集・削除も可能
- **アルバム出力**: 期間を指定して、表紙メッセージ付きの写真アルバム(HTMLファイル1つ)を書き出し。ブラウザで開いてそのまま見せられ、「印刷 → PDFとして保存」で冊子用PDFにもできます
- **バックアップ/復元**: 全データをJSONファイルとして書き出し・取り込み

## 使い始め方(スマホ)

1. このフォルダを Web で公開します。一番簡単なのは **GitHub Pages**:
   - リポジトリの Settings → Pages → Branch でこのブランチと「/ (root)」を選んで保存
   - 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/bento-diary/` で開けます
2. スマホのブラウザでそのURLを開く
3. **ホーム画面に追加**する(アプリのように起動できます)
   - iPhone (Safari): 共有ボタン → 「ホーム画面に追加」
   - Android (Chrome): メニュー → 「ホーム画面に追加」または「アプリをインストール」
4. あとは毎日、写真を撮ってひとこと添えて保存するだけ

一度開けばオフラインでも動きます(Service Worker がキャッシュします)。

## 大事な注意

- **データは端末内(ブラウザのIndexedDB)だけに保存されます。** クラウドには一切送信されないのでプライベートですが、ブラウザのデータ消去やアプリの削除で消えます。**月に1回程度「出力」タブからバックアップを書き出して**、別の場所(クラウドドライブ等)に保管するのがおすすめです。
- 写真は保存時に長辺1600pxのJPEGに自動圧縮されるため、1年分(365枚)でもおよそ100〜200MB程度に収まります。
- リポジトリを公開する場合でも、公開されるのはアプリ本体だけで、記録した写真やコメントが公開されることはありません。

## サプライズ当日の流れ

1. 「出力」タブを開く
2. アルバムのタイトルと表紙メッセージを書く(例:「1年間、毎朝ありがとう」)
3. 期間を指定(空欄なら全期間)して「アルバムを書き出す」
4. できたHTMLファイルを開いて見せる、またはPDF化して印刷 🎁

## 技術メモ

- 依存ライブラリなしの単一HTML + Service Worker(PWA)
- 写真は `IndexedDB` に Blob として保存
- アルバムは全写真を data URL で埋め込んだ自己完結HTMLとして生成
